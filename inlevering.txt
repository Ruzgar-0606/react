Kennischeck

1. Wat is React?
React is een JavaScript-library waarmee je gebruikersinterfaces bouwt uit herbruikbare componenten.

2. Waarom gebruiken veel bedrijven React?
Met componenten kun je onderdelen van een interface hergebruiken. React kan de interface aanpassen wanneer gegevens veranderen en heeft een grote community en veel hulpmiddelen.

3. Wat is het verschil tussen Front-end en Back-end?
De front-end is het deel van een applicatie dat de gebruiker ziet en bedient. De back-end verwerkt gegevens achter de schermen, bijvoorbeeld op een server en in een database.

4. Waarom gebruiken we Vite?
Vite biedt een snelle en eenvoudige ontwikkelomgeving voor React, met onder andere een snelle ontwikkelserver en hot reloading.

5. Wat is de functie van App.jsx?
App.jsx bevat de hoofdcomponent van de React-applicatie en beschrijft de interface die op de pagina verschijnt.

6. Wat is de functie van main.jsx?
main.jsx is het startpunt van de app. Het koppelt React aan het root-element in index.html en rendert daarin de App-component.

7. Waarom gebruiken we GitHub tijdens deze module?
GitHub bewaart de broncode en de geschiedenis van wijzigingen online. Zo kun je werk terugvinden, delen en samenwerken.

Kennischeck

1. Wat is een component?
Een component is een zelfstandig en herbruikbaar onderdeel van een React-interface, zoals een header, gamekaart of footer.

2. Waarom gebruiken we componenten?
Componenten verdelen de interface in kleine, overzichtelijke onderdelen. Daardoor kun je code makkelijker onderhouden en onderdelen opnieuw gebruiken.

3. Waarom maken we een map components?
De map components houdt componentbestanden bij elkaar, zodat de projectstructuur overzichtelijk blijft.

4. Wat doet export default?
export default maakt een component beschikbaar voor andere bestanden, zodat die component geïmporteerd kan worden.

5. Wat doet import?
import haalt een geëxporteerde component uit een ander bestand, zodat je hem kunt gebruiken.

6. Waarom gebruiken we <Header /> in plaats van een gewone <h1>?
<Header /> gebruikt de Header-component uit een apart bestand. Die component kan ook eigen structuur en opmaak bevatten en is op andere plekken opnieuw te gebruiken.

7. Wat is het voordeel van herbruikbare componenten?
Je schrijft een onderdeel één keer. Als je het aanpast, geldt die wijziging overal waar je de component gebruikt.

Een React-component is een herbruikbaar stukje van een website. Je kunt het vergelijken met een LEGO-blok: een Header-component kan bijvoorbeeld de titel van je Game Collection tonen. In een ander bestand kun je die component importeren en met <Header /> op de pagina zetten. Zo bestaat een grotere website uit kleine onderdelen met ieder een eigen taak.

Kennischeck

1. Waar staat Props voor?
Props is een afkorting van properties: gegevens of eigenschappen die je aan een React-component meegeeft.

2. Waarom gebruiken we Props?
Met Props kan dezelfde component verschillende gegevens tonen, waardoor componenten herbruikbaar zijn.

3. Hoe geef je gegevens door aan een component?
Je geeft gegevens mee als attributen, bijvoorbeeld <GameCard title="Minecraft" platform="PC" />.

4. Hoe lees je Props uit binnen een component?
De component ontvangt Props als parameter en leest een waarde bijvoorbeeld met props.title of props.platform.

5. Waarom is een GameCard met Props beter dan drie losse GameCards?
Je schrijft de opmaak maar één keer en geeft elke game eigen gegevens mee. Dat voorkomt dubbele code.

6. Wat gebeurt er als je een andere titel doorgeeft?
De GameCard toont de nieuwe titel die via de title-prop is meegegeven.

7. Wat is het voordeel van herbruikbare componenten?
Je kunt dezelfde component op meerdere plekken gebruiken en hoeft aanpassingen maar op één plek te doen.

AI-opdracht

Uitleg van ChatGPT

Props zijn gegevens die je van een bovenliggende React-component doorgeeft aan een onderliggende component. Je kunt ze vergelijken met informatie op een bestelformulier. Een GameCard ontvangt bijvoorbeeld een title en platform. De component gebruikt die waarden om de juiste game te tonen. Zo kan dezelfde GameCard Minecraft, Mario Kart of een andere game weergeven.
