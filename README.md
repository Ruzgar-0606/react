# Game Collection

Mijn eerste React-applicatie, gemaakt met React en Vite.

## Project starten

```sh
npm install
npm run dev
```

Open daarna de lokale URL die Vite in de terminal toont.

## Controleren

```sh
npm run lint
npm run build
```

## Belangrijkste bestanden

- `src/App.jsx`: de hoofdcomponent met de Game Collection-welkomstpagina.
- `src/main.jsx`: het startpunt dat React aan de pagina koppelt.
- `src/App.css` en `src/index.css`: de stijlen van de applicatie.
- `public/`: statische bestanden.
- `package.json`: projectinformatie, packages en scripts.
